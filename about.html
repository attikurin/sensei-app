このサイトについて

「先生アプリ」は、先生たちが生成AIで作ったWebアプリを共有し合う、先生のための先生によるプラットフォームです。

💡 生まれた背景

現場の先生たちが、Gemini・ChatGPT・Claude などの生成AIを使って、自分たちの課題を解決するWebアプリを作り始めています。しかし、せっかく作ったアプリを「自分だけが使う」のはもったいない。

「他の先生にも使ってもらいたい」「作り方を教えたい」そんな声から生まれたのが、先生アプリです。

🌟 3つの特徴

📴

オフライン動作アプリも充実

インターネット不要で使えるアプリには「オフライン動作対応」バッジを表示。学校のネット環境に左右されず安心して使えます。

🤖

プロンプトも共有

アプリを作ったAIへの「呪文（プロンプト）」も公開。先生自身がカスタマイズして使えるようにします。

👩‍🏫

現場の先生が作る

ICTの専門家ではなく、実際の教育現場を知る先生が作ったツール。現場のニーズに即した実用的なアプリが集まります。

🏗️ 技術スタック

ランニングコスト「完全無料」で運営できる構成です。

🖥 フロントエンド HTML / CSS / JavaScript（バニラJS）
🔐 認証 Firebase Authentication（Googleログイン SSO）
🗄️ データベース Firebase Firestore（アプリ情報・ユーザー管理）
📦 ファイル保管 Firebase Cloud Storage（HTMLファイル・画像）
🚀 ホスティング GitHub + Vercel（自動デプロイ）

📤 アプリ投稿の流れ

1

Googleアカウントでログイン

学校アカウントや個人のGoogleアカウントでワンクリックログイン。

2

アプリ情報を入力

タイトル・概要・カテゴリ・使い方・プロンプトを入力します。

3

共有方法を選ぶ

「外部URL」または「HTMLファイルのアップロード」のどちらかを選択。

4

投稿 → 即公開

投稿すると即時公開されます。マイページからいつでも編集・削除・非公開化できます。
